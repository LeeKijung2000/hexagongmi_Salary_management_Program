# 🏢 HEXAGON ERP - 재고 및 업무 관리 시스템

> 제조 및 유통 업무의 효율적인 관리를 위한 웹 기반 ERP 시스템

<br>

## 📌 프로젝트 소개

**HEXAGON ERP**는 기업의 영업 및 재고 관리 업무를 효율적으로 수행할 수 있도록 개발한 웹 기반 ERP 시스템입니다.

거래처, 창고, 품목 등의 주요 데이터를 통합 관리하고, 주문부터 출하지시까지의 업무 흐름을 시스템으로 구현하는 것을 목표로 하였습니다.

5명의 팀원이 협력하여 프로젝트를 진행하였으며, 실제 기업의 업무 프로세스를 고려한 기능 설계와 데이터 관리에 중점을 두었습니다.

### ⭐ My Responsibilities

프로젝트에서 다음 4가지 주요 기능의 개발을 담당하였습니다.

**1. 거래처 관리 (Business Partner Management)**
- 거래처 신규 등록 및 정보 관리
- 거래처 정보 조회 및 검색
- 거래처 정보 수정 및 삭제
- 거래처 데이터 관리 및 연동

**2. 창고 관리 (Warehouse Management)**
- 창고 정보 등록 및 관리
- 창고별 정보 조회 및 수정
- 창고 데이터 관리
- 재고 관리와 연계되는 창고 정보 구성

**3. 품목 관리 (Item Management)**
- 품목 신규 등록 및 관리
- 품목 정보 조회 및 검색
- 품목 정보 수정 및 삭제
- 품목 관련 데이터 관리

**4. 출하지시서 관리 (Shipment Instruction Management)**
- 출하지시서 조회 및 관리
- 출하 대상 품목 및 수량 정보 확인
- 출하 업무에 필요한 데이터 연동
- 출하 관련 업무 프로세스 구현

## 💡 프로젝트를 통해 배운 점

이번 프로젝트를 통해 단순히 기능을 구현하는 것뿐만 아니라, 여러 기능이 하나의 시스템 안에서 유기적으로 연결되는 과정의 중요성을 배웠습니다.

특히 데이터베이스와 연동한 CRUD 기능 구현, Spring과 MyBatis를 활용한 데이터 처리, 팀원 간의 코드 공유 및 협업 과정을 경험하였습니다.

또한 개발 과정에서 발생하는 오류를 분석하고 해결하며 문제 해결 능력을 키울 수 있었고, 팀원들과 지속적으로 소통하며 하나의 프로젝트를 완성하는 경험을 쌓았습니다.
